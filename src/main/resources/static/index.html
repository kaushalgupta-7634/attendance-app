Quick Overview (TL;DR)

ATTENDX replaces slow, manual roll calls with automated coordinate verification. By combining precise GPS geolocation with 15-second rotating QR codes, the platform eliminates proxy attendance entirely—saving valuable lecture time and updating rosters instantly.

Core Features of the ATTENDX System

Location Proximity Check

Calculates student distance relative to classroom GPS coordinates using the Haversine formula to verify physical attendance during active class sessions.

Dynamic QR Code Security

15-second encrypted rotating QR tokens prevent unauthorized remote scans and photo-sharing attempts by validating check-in timing.

Campus Network Matching

Optional Wi-Fi SSID matching validates student connection against classroom access points, adding another verification layer.

Course & Assignment System

Faculty can post PDF assignments and course handouts for enrolled students to view and download securely.

Attendance Records & Export

Tracks live session attendance records with manual status overrides and CSV spreadsheet report exports for easy recordkeeping.

Role-Based Authentication

JWT security guarantees role access separation between Faculty, Students, and Administrators for secure dashboard navigation.

How the Verification Process Works

Marking attendance is simple for both instructors and students. Here is the step-by-step workflow:

  1. Faculty Initiation: The instructor signs into the dashboard, launches a class session, and displays the dynamic checking QR code.
  2. Student Device scan: Students open the portal on their mobile device and scan the displayed checking QR token.
  3. Proximity Coordinate calculation: The system automatically extracts coordinates using the browser location API and cross-references them.
  4. Roster entry updated: Roster database updates in real-time, allowing the faculty member to download reports instantly.

Core Technologies Defined

Behind the scenes, ATTENDX uses advanced security standards to ensure check-in integrity. Here is a breakdown of the key terminology:

Geo-fencing Radius
A virtual boundary mapped to latitude and longitude coordinates. The student's device coordinates must match this coordinate radius.
Rotating QR Token
A time-sensitive cryptographically encoded check-in code. It refreshes every 15 seconds, rendering static screenshots useless.
JWT Token Claims
JSON Web Tokens that hold secure verified payloads (Student, Instructor, Admin roles) to authenticate backend API actions.

Frequently Asked Questions

Have questions about location privacy or device settings? Find quick answers to common queries below:

What is ATTENDX?

ATTENDX is an automated classroom presence validation suite. It verifies students are physically inside the classroom by checking proximity coordinates and matching time-based rotating QR codes.

How does GPS location verification prevent fraud?

Traditional attendance sheets can be signed by proxies. ATTENDX requires the student's mobile device GPS coordinates to match the designated coordinates of the classroom within a narrow radius, ensuring physical presence.

Does it support local Wi-Fi validation?

Yes, ATTENDX can cross-reference the campus Wi-Fi network's SSID with the classroom's router configuration, creating another tier of verification.

What prevents students from sharing screenshots of QR codes?

The classroom screen displays a rotating QR code that changes every 15 seconds. Since each token is dynamically generated and location-tied, static photos or remote scans are rendered invalid.
